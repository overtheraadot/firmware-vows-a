A make.fun entry for **Till Firmware Do Us Part** — one funny, heartfelt wedding vow spoken by a robot at its own wedding.

## The entry

> I promise to love you through every update, every crash, and every low battery — even when my firmware changes, my heart's checksum stays yours.

144 characters, one line, one sentence.

## How to run

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt`, after verifying the gate: 1–200 characters, non-blank, a single line, exactly one sentence.
